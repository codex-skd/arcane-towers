<h2>v1.0.0 - First stable release</h2>

<h3>Added</h3>
<ul>
<li><strong>Majestic Core is now required.</strong> The underground dungeons are decorated with the Order's masonry and rune lanterns from it &#8212; Arcane Brick, its chiseled and cracked variants, Aged Bronze, Runic Brick and Runic Obsidian &#8212; so each dungeon reads as part of the same world as the rest of the Majestic ecosystem. The towers above ground keep their own palettes.</li>
</ul>
