<h2>Arcane Towers 0.0.0-beta.4</h2>

<h3>Changed</h3>
<ul>
<li><strong>Towers never spawn next to other structures</strong> any more (villages, outposts, ruined portals, other mods' buildings) and only rise in <strong>wide areas</strong> of their biome, not in tiny biome patches.</li>
<li>The <strong>Umbral Tower</strong> is now guarded by a <strong>Goliath</strong>.</li>
<li>The <strong>Exit Stone</strong> now glows with drifting runes and particles, so you can spot it in the dark.</li>
</ul>

<p>Requires Expedition Core 0.0.0-beta.5 and Majestic Bestiary 0.0.0-beta.4.</p>
