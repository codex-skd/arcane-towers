<h2>v0.0.0-beta.7 - Three of the four towers were unclimbable</h2>

<h3>Fixed</h3>
<ul>
<li><strong>Three of the four towers could not be climbed.</strong> The stair runs were five steps for a
six-block rise, which leaves you one block short of the floor above with no way up from where you are
standing. Only the Tower of Arcane Stone worked. Runs are now six steps, spiralling around the shaft,
with the facing matching the direction of travel.</li>
<li><strong>The Frost Tower had no stairs at all.</strong> It now has real prismarine-brick stairs over
the existing packed-ice ramp. Vanilla has no ice stair block in 1.21.1, and prismarine brick is the
closest blue available, so the frozen palette stays.</li>
<li><strong>The Tower of Arcane Stone's stairs were three different materials</strong> in the same
flight. Unified.</li>
<li>Two Frost Tower runs were moved out of spots that blocked them.</li>
</ul>

<h3>Notes</h3>
<ul>
<li>A new automated check walks each tower from its door and reports whether it can be climbed, floor
by floor. Counting stair blocks is not the same as being climbable &#8212; which is how three broken
towers shipped in the first place.</li>
<li>Nothing verified in game yet. Climb one to be sure.</li>
</ul>
