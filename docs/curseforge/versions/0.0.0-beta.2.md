<h2>Arcane Towers 0.0.0-beta.2</h2>

<h3>Changed</h3>
<ul>
<li><strong>Redesigned dungeons</strong>: every tower now has a clear main path through three stages down to the guardian's hall, with optional side rooms to explore. The final hall with the Exit Stone is always generated.</li>
<li>Dungeons are much tighter: around a dozen rooms and far fewer spawners (roughly a quarter of before), so each tower is a focused expedition instead of an endless maze.</li>
</ul>
