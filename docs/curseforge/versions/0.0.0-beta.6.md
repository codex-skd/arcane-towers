<h2>v0.0.0-beta.6 - The towers sit on rock</h2>

<h3>Changed</h3>
<ul>
<li><strong>All 60 structure pieces re-imported</strong>, 15 per tower across the stone, frost, sandstone
and umbral towers.</li>
<li><strong>The ground floor moved up 6 blocks</strong> in every tower, with a solid rock base beneath it,
and <code>start_height</code> changed from <code>-24</code> to <code>-30</code> to match. Together these keep
the playable floor at the same height while giving the tower six blocks of base, so on sloping ground
it has less of a gap underneath.</li>
</ul>

<h3>Known</h3>
<ul>
<li><strong>This eases the floating-and-burying problem rather than solving it.</strong> The towers are
seated at the surface height of a single column, which is what makes them follow the terrain &#8212; so on
a steep slope the rest of the footprint can still sit awkwardly. The new base absorbs that, up to six
blocks of it.</li>
<li>Nothing has been placed in a world yet.</li>
</ul>

<blockquote><strong>Early alpha.</strong> Content is still being built out &#8212; expect changes between versions.</blockquote>
